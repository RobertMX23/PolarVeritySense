# Exercise analysis

## Objetivo

Interpretar una sesión de ejercicio de Polar usando métricas calculadas por Python.

## Reglas

- Solicitar la telemetría mediante la tool de ADK.
- No hacer aritmética sobre muestras dentro del LLM.
- Explicar duración, frecuencia cardiaca, zonas, deriva y calidad de datos.
- Distinguir datos completos de un resumen sin muestras.
